# ePocketShop Storefront

The ePocketShop WhatsApp storefront, rebuilt with React 19, Vite and the
[Astryx design system](https://astryx.atmeta.com/). It uses the same Butter theme
and "Lemon granite morning" palette as `epocketshop_admin` (see `src/styles.css`).

Customers open `/<store name>`, browse products, build a cart and send the order
to the store over WhatsApp.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build
```

In dev the app talks to `http://localhost:5010`. Copy `.env.example` to `.env`
to point it elsewhere.

## Routes

| Path                  | Page                          |
| --------------------- | ----------------------------- |
| `/`                   | Find a store                  |
| `/:store`             | Products, search, categories  |
| `/:store/cart`        | Cart                          |
| `/:store/checkout`    | Customer details, send order  |
| `/:store/confirmation`| Order sent                    |
| `/:store/about`       | About the store               |
| `/:store/contact`     | Contact options               |

## Structure

```
src/
  components/   UI built from Astryx components
  contexts/     StoreContext (API data), CartContext (in-memory cart)
  hooks/        useStoreRoute: resolves :store and loads its data
  lib/          api, config, price formatting, order payload, WhatsApp message
  pages/        one file per route
astryx-themes.js   generated by `npx astryx theme add` (do not edit)
```

## Notes

- Prices: product prices from the API are in cents; option and extra prices are in rands.
- The WhatsApp message format is parsed by the backend. Keep `src/lib/whatsapp.ts` wording as is.
- Change the theme with `npx astryx theme list` / `npx astryx theme add <slug>`.
- Astryx agent docs for AI tools are in `AGENTS.md`.
